# Customer Segmentation Using RFM Analysis (SQL)

## Project Overview
This project analyzes over **540,000 e-commerce transactions** from the Online Retail dataset using **SQL Server**. After cleaning raw transactional records, an **RFM (Recency, Frequency, Monetary)** model was built to score and classify customers into actionable marketing segments.

## Methodology & Workflow
1. **Data Cleaning & Transformation:**
   - Audited raw data for anonymous guest checkouts (`CustomerID IS NULL`), product returns (`Quantity <= 0`), and zero-priced adjustments.
   - Standardized British string timestamps (`dd-mm-yyyy`) into valid SQL `DATETIME` values using `TRY_CONVERT(..., 103)`.
2. **RFM Metrics Calculation:**
   - **Recency (R):** Days elapsed since each customer's last purchase relative to the dataset's final transaction date (`DATEDIFF`).
   - **Frequency (F):** Total count of unique invoices per customer (`COUNT(DISTINCT InvoiceNo)`).
   - **Monetary (M):** Total revenue generated by each customer (`SUM(Quantity * UnitPrice)`).
3. **Scoring & Segmentation:**
   - Ranked customers into quartiles (`1` to `4`) across each metric using `NTILE(4)`.
   - Aggregated RFM scores and categorized customers into four strategic tiers: **Champions**, **Loyal Customers**, **At Risk**, and **Lost Customers**.

## SQL Techniques Used
- **Data Cleaning & Type Casting:** `TRY_CONVERT()`, `WHERE` filtering, `SELECT INTO`
- **Date & Aggregation Functions:** `DATEDIFF()`, `MAX()`, `COUNT(DISTINCT ...)`, `SUM()`
- **Window Functions:** `NTILE(4) OVER (ORDER BY ...)`
- **Query Structuring:** Chained Common Table Expressions (`CTEs`) & `CASE WHEN`
